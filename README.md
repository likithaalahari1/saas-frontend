# Socially SaaS Frontend

Unified Social Media Management Studio - React + Vite + Tailwind CSS Web Application & Marketing Site.

> **Create Once → Customize → Publish Everywhere**

## Features

- **Marketing Landing Page**: High-converting commercial homepage with interactive live workspace demo preview, features, pricing calculator, and FAQ.
- **Content Creation Studio**: Global content editor with per-platform copy overrides, character limit counters, hashtag manager, and media drag-and-drop.
- **Live Platform Preview Engine**: Pixel-perfect realistic frame rendering for Instagram, LinkedIn, Facebook, X, TikTok, and YouTube with Desktop & Mobile preview toggles.
- **Real-Time Multi-Publishing Progress Modal**: Interactive step-by-step progress bars per platform with celebration confetti.
- **Content Calendar**: Interactive Month, Week, and Day views with platform badges and post click-to-edit drawer.
- **Drafts & Published History**: Full status breakdown and failed-channel retry workflow.
- **Social Accounts Hub**: Connected channels with simulated OAuth 2.0 connection modal.
- **Analytics Dashboard**: Cross-network reach, engagement, follower growth metrics, and interactive SVG charts.
- **Unified Social Inbox**: Multi-channel customer conversation workspace with rich reply box and CRM context panel.
- **Media Library**: Asset manager with folders, tags, and one-click "Use in Post Studio".
- **Team & Approval Workflows**: Member directory with roles (Owner, Admin, Editor, Approver, Viewer) and approval pipeline.
- **Developer OAuth API Keys Manager**: Connects to production Django REST backend (`https://andhrayatri.in/api`).

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
